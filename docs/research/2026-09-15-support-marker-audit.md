# 支持标记与本地机制衔接审计

日期：2026-09-15。基线：`c756325`；引擎仍为 `e7fd7e59`。

本次核查的是“已有本地机制，但仍显示整个效果未支持”的错位，不是重新认证所有特性、道具和招式的完整对战机制。对照了特性通用分类、Champions 差异列表、默认天气／场地／阶级投影、实际计算入口、道具效果目录和招式语义门控。

| 核查项 | 证据与结论 |
| --- | --- |
| 精神制造者 227、薄雾制造者 228、青草制造者 229 | `ability-projection.ts` 已将它们映射为明确的场地输入；`terrain.ts`、`scenario-compiler.ts` 和两种 calc 规则消费这些输入。通用未支持列表中的三项为误标，移除。 |
| 电气制造者 226 | 同一投影机制，原本已标为支持；作为四种场地制造者的对照一起测试。 |
| 降雨、扬沙、日照、降雪、吐沙、威吓、不服输、好胜 | 默认天气或阶级投影已有支持分类，没有相同的通用未支持误标。特性结果来源为 neutral，贡献由明确的天气／阶级输入表达。 |
| 我行我素 20、恒净之躯 29、白色烟雾 73、单纯 86、唱反调 126、金属防护 230、看门犬 275 | 存在威吓的初始阶级推荐，但这只覆盖部分机制。持续能力变化由 `applyCalcStatChanges` 直接应用，尚未完整处理这些特性的免疫、倍率、反转或其他效果；不凭一次推荐将整个特性升级为支持。 |
| 道具 | 核查 `held-item/support.ts`、`inventory.ts` 与编译器门控。Champions 排除项仍需要引擎伤害路径，描述符中的本地显示修正不等于引擎已经计算效果。已有本地命中／会心效果的道具未被该列表排除；没有确认同类误标。 |
| 招式 | 核查通用未支持列表、Champions 差异列表及 `auditedMoveWarning`。已支持的能力变化优先消除对应警告；身份属性映射和本地场地修正也不能代替缺失的招式执行机制。本次没有确认可直接取消的同类标记。 |

场地制造者采用现有契约：在未手动编辑场地时推荐场地，手动编辑后只补充候选；计算使用实际选中的场地，不模拟出场事件。特性自身来源维持 neutral，避免重复计算或重复显示场地贡献。

青草场地仍为部分支持 Scenario，保留“当前未计算青草场地在回合结束时的回复”提示。修正特性标记并不扩大回复机制的支持范围。

验证覆盖两种规则、四种场地制造者、攻击方／防守方来源、实际伤害与显式场地的一致性、手动覆盖和中文可访问标签。修复前新增测试有 8 项失败，修复后定向 70 项通过。

完整验证：86 个测试文件、896 项测试通过；`pnpm build` 和 `pnpm lint` 通过。独立工作区补齐主工作区已有的 PokeAPI 类型相性 CSV 后完成全量测试。构建仍有既有的大分块提示，lint 仍有既有警告。
