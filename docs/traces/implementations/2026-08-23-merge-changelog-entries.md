# 实现追踪：更新日志条目合并

日期：2026-08-23
来源：用户请求“最新更新的条目没有合并”
语言：中文

## Entries

### 1. 按版本标题合并所有条目

Type: interpretation

Context:
请求指出“最新变更”下的条目应合并，但没有说明正式发布版本中的多个条目是否也应采用相同分组。

Decision:
解析器按 Markdown 的 `##` 版本标题生成一个分组，组内保留所有本地化条目；该规则同时用于 `Unreleased` 和正式版本。

Reason:
版本标题是生成文件已有的天然分组边界，统一处理可避免未发布和已发布日志出现不同结构。

Follow-up:
None.
