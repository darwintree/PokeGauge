# 不可达实数值处理 讨论记录

对应 spec change: None.

## 1. 数轴是否保留不可达实数值

问题：性格与努力值组合无法产生的整数实数值，是否仍允许用户通过数轴选择。

决定：保留。数轴继续操作边界内的全部整数实数值，不跳过不可达值。

## 2. 不可达实数值如何参与计算

问题：不可达实数值应直接进入伤害公式，还是先映射到相邻的合法性格与努力值配置。

决定：直接按用户选择的实数值计算，不吸附或映射到相邻值。性格与努力值只用于派生 SP 标签，不参与实数值模板的伤害计算。

## 3. 无对应 SP 分配的模板是否正常流转

问题：无对应 SP 分配的实数值是否可以保存、分享并参与 Preset 与 Range 切换。

决定：可以。模板完整保留原始实数值，并与有 SP 分配的模板采用相同的数据生命周期。

## 4. 无对应 SP 分配时的默认标签

问题：默认 SP 标签无法派生时，模板应显示错误文案、占位符，还是实数值。

决定：直接按实数值方式渲染默认标签。进攻显示单个实数值，例如 `186`；防守显示 HP 与防御实数值，例如 `170 / 153`。不显示错误态或 `undefined`。

## 5. 无对应 SP 分配的提示

问题：如何提示当前实数值没有对应的 SP 分配。

决定：在实数值标签旁显示感叹号提示。Tooltip 文案为“无对应 SP 分配，按实数值参与计算。”无对应分配时不提供分配切换；开启“显示实数值”时不重复渲染相同数值。
