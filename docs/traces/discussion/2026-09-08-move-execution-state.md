# Move Execution 与状态延续讨论记录

对应 spec change: None.

## 1. 架构优化方向

问题：本轮先深入哪一项架构优化？

决定：先统一生产与测试的伤害结算路径，迁移旧路径上的有效行为断言，再删除仅由旧测试维持的平行实现。

## 2. 满 HP 假设与状态延续

问题：多重鳞片的“按满 HP 结算”表示 Scenario 的初始条件，还是每段、每次招式执行都重新假定满 HP？

决定：满 HP 只作为 Scenario 的初始条件。每个 Hit 造成的变化持续到下一段和下一次 Move Execution；一次招式执行不重置对战状态。目标初始满 HP、第一击造成伤害且中间没有回复时，一次两段连续攻击与单段招式使用两次都只对第一击应用多重鳞片减伤。
