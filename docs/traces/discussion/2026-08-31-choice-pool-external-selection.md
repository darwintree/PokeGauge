# Choice Pool 外部列出与选中 讨论记录

对应 spec change: None.

## 1. 外部列出的是哪一层

问题：常驻列出的是 Picker 目录、Track 上已加入的选项，还是仅已选中项。

决定：列出 **Choice Pool**（Track 上已加入的取值）。高亮 = 选中（进 Scenario set），未高亮 = 仍在池中但不生成 Scenario。Picker 目录仍称 candidate pool，不用「候选池」指 Track 上那排。天气 / 场地 / 墙 / 特性的 Choice Pool 等于其小目录，看起来像目录常驻，语义仍是选项池。

## 2. 外部 chip 点击语义

问题：点外部选项是切换选中、移出池，还是展开 Track。

决定：点未高亮则选中，点高亮则取消选中并仍留在 Choice Pool。点 chip 不展开 Track。空选中地板不变：阶级 → `0`，天气 / 场地 / 墙 / 道具 → `none`，特性至少留一项。

## 3. 招式展开后的 enable/disable

问题：招式 Track 展开后是否去掉 enable/disable，选中是否只走外部 chip。

决定：保留现有展开样式，含 enable/disable。折叠态 chip 与展开后的 enable/disable 写同一份 Selection。

## 4. 招式折叠 chip 与进入编辑

问题：折叠态 chip 点下去是切换选中，还是展开并进入该快照编辑。

决定：折叠态 chip 只切换选中，不展开。进入编辑：点标题 / chevron 展开，再走现有行编辑。

## 5. 各 Track 的池范围、入池与是否展开

问题：每一类默认池有哪些、如何变大、展开面板还做什么。

决定：

| Track | 外部默认列出 | 加入池 | 展开 |
| --- | --- | --- | --- |
| 招式 | 当前 Move pick 整池（含未选备选） | 折叠态 `+` → Picker；新快照默认选中 | 要：现有快照编辑 + enable/disable + 删除 |
| 道具 | 当前道具 Choice Pool 全部 | 折叠态 `+` → Picker；新道具默认选中 | 不要。说明走 tooltip |
| 能力阶级 | 只有 `0`（高亮） | 折叠态 `+` → 尚未入池的 −6…+6；加入后默认选中 | 不要 |
| 特性 | 当前身份目录全部 | 无 | 不要。假设已满足绿点与暂不支持标记打在外部 chip；长文案走 tooltip |
| 天气 / 场地 / 墙 | 完整小目录 | 无 | 不要。说明走 tooltip |

能力值 Track 不在这批，仍按现有展开编辑。

## 6. 特性投影与阶级池

问题：选威吓等会投影阶级时，若不在池里是加入并选中，还是忽略。

决定：加入 Choice Pool 并选中。投影只加不撤：取消该特性不会拿掉已投影的阶级；用户可取消高亮。

## 7. 能力值 Track 范围

问题：进攻 / 防守能力值是否一并改成外部 chip 多选。

决定：不在这批。保持现有展开编辑。

## 8. 未高亮项与 Scenario Setup / 分享 / 书签

问题：选项池常驻可见后，未选中项是否写入 Setup、分享链接、书签。

决定：不重开 ADR-0004 / 0005。未高亮项仍是工作区本地状态；Setup / 分享 / 书签只带选中集合。换身份重建招式池的规则不变。

## 9. 移出池

问题：道具、阶级等当前没有移出池操作的 Track，是否补 hover 移除等。

决定：当前没有移出池逻辑的 Track 不额外定义移出。只有招式继续用现有的删除快照。道具、阶级、特性、天气、场地、墙都不能把选项从池里拿掉；取消高亮只改选中。

## 10. 中性项的池籍

问题：阶级 `0`、道具 `none` 等中性项能否移出池、能否取消高亮。

决定：随 §9：没有移出则中性项不能离池，只能取消高亮（须仍有其他选中，否则地板回中性）。

## 11. 重置

问题：重置清选中、清池，还是两者都清；放在展开里还是外部。

决定：只把选中收成 Neutral / 特性目录默认，不动 Choice Pool。放在外部标题栏，不依赖展开。招式没有重置，继续没有。阶级要把池缩回只剩 `0`，不另做第二种重置（也没有移出）。

## 12. 外部 chip 过多时的排布

问题：默认 Move pick 含备选时，折叠态 chip 是否用结果面那种 `+N` 收起。

决定：换行，不 `+N`。

## 13. 能力阶级的两套状态

问题：阶级今天只有一份选中数组；取消高亮还要留在外部，是否做成与道具相同的池 + 选中。

决定：做成与道具相同的两套状态。不新增移出 UI。同一对阵内阶级池只增不减；换进攻方 / 防守方 / 物特时现有 catalog transition 仍把阶级收回 `{0}`。本地刷新按道具池同样方式记住阶级池。

## 14. 不再展开的 Track 与手风琴

问题：天气等不再展开后，点标题是否仍占 `activeId` 互斥手风琴。

决定：这些 Track 退出手风琴：无 chevron、点标题不切换展开、chip 行始终可见。互斥展开只留给招式、进攻能力值、防守能力值。

## 15. 外部 chip 行布局

问题：chip 塞进标题行，还是标题下单独一行。

决定：统一成招式折叠态那种两行：第一行标题（含重置、`+` 若有），第二行 Choice Pool chip，不够就换行。

## 16. 招式展开时是否保留常驻 chip 行

问题：展开后现有 UI 会换掉折叠 chip 行；去掉 enable/disable 后选中无处可点。

决定：不改展开布局。展开后仍是现有快照列表，含 enable/disable；不在展开态再叠一排常驻 chip。

## 17. 折叠态 `+` 加入招式后的行为

问题：折叠态就能 `+` 之后，加入是否仍自动展开并进入该快照编辑。

决定：保持现有逻辑：加入后自动展开并进入该快照编辑；新快照默认已选。

## 18. 折叠态 `+` 与重置

问题：标题栏同时放重置和 `+` 是否合适。

决定：`+` 放在第二行，跟 Choice Pool chip 一起换行。折叠态（含不再展开的 Track）不显示重置。
