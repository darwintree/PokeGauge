# 连续执行能力阶级变化讨论记录

对应 spec change: None.

## 1. 连续执行的状态范围

问题：≤2HKO 是否纳入第一次攻击造成的目标降防？

决定：纳入目标防御或特防下降，并与树果消费状态共同传递。主伤害与等效威力继续表示第一次完整使用，第二次收益进入 ≤2HKO。

## 2. 概率模式

问题：经典模式是否纳入概率触发的降防和加攻？

决定：经典模式忽略概率触发的降防和加攻，保留必定触发；实战模式按实际概率计算。

## 3. 亲子爱边界

问题：是否扩展连续攻击中的降防和加攻？

决定：以袋兽的亲子爱为基准评估。能复用状态传递、复杂度不明显增加时一并支持；若明显增加复杂度则暂缓，保留具体限制说明，不扩展为通用战斗状态模拟器。

## 4. 亲子爱范围修订

问题：是否继续暂缓亲子爱首击触发降防或加攻后的条件计算？

决定：不再暂缓。本轮补齐已纳入支持的降防／加攻招式在亲子爱下的段间生效和跨次延续，保留伤害与阶级变化的关联。经典模式仍忽略概率触发，保留必定触发。本条取代第 3 条中的暂缓分支。

## 5. 统一结算流程

问题：是否为亲子爱单独增加一条实现路径？

决定：按统一框架重构并实现，普通招式与亲子爱共享逐段状态传递、概率分支和跨次结算。
