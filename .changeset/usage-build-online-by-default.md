<!-- changelog:start -->
<!-- changelog:en -->
Usage data is now included in the standard build, so a deployment always carries the precompiled Pokémon ranking and per-Pokémon breakdowns. Testing builds can use the offline build command to skip fetching usage data.
<!-- changelog:zh-hans -->
使用率数据现在包含在默认构建中，因此每次部署都会带上预先编译的宝可梦排名和逐只宝可梦明细。测试构建可使用离线构建命令跳过抓取使用率数据。
<!-- changelog:zh-hant -->
使用率資料現在包含在預設建置中，因此每次部署都會帶上預先編譯的寶可夢排名和逐隻寶可夢明細。測試建置可使用離線建置命令跳過抓取使用率資料。
<!-- changelog:ja -->
使用率データが標準のビルドに含まれるようになり、デプロイには事前コンパイル済みのポケモンランキングと各ポケモンの内訳が必ず含まれます。テスト用ビルドではオフラインビルドコマンドで使用率データの取得を省略できます。
<!-- changelog:end -->
