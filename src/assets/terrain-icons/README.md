# Terrain icons

PokeGauge SVG artwork based on the user-approved expanding-energy-ring concept (C).
Electric, grassy, psychic, and misty terrain share a flat tilted field and two open outer arcs; the white symbols and palette follow the Pokémon type visual language.

The 64×64 viewBox is rendered at 24px on desktop and 28px on mobile. These are project-drawn assets, not unmodified PokéSprite files.
