# Pokémon type icons

Unmodified 60×60 Gen9 small icons from [PokeAPI sprites](https://github.com/PokeAPI/sprites/tree/master/sprites/types/generation-ix/scarlet-violet/small), retrieved 2026-09-15. Original numeric filenames use PokeAPI type IDs; local filenames use the corresponding domain type names.

Pokémon artwork belongs to its respective owners. These are upstream game assets, not original PokeGauge artwork.

Bundled locally so type identity does not depend on the external sprite host. Display at 20px, or 16px in compact mobile result captions, with normal image smoothing. Localized names come from the app's i18n messages.
